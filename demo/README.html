⛺ layout demos

The demos require MulleUI to run.

layout

This is a showcase of the various layout algorithms.

The first line demos contentMode, which is the placement of a rectangle within another rectangle.

The second and third lines are demos of placement a rectangle is placed in relationship to another rectangle with disregard to the surrounding space.

The fourth line is a demo of placing two rectangles adjacent in a surrounding space with some alignment.

The fifth line demos manual layouting. Rectangles are added in column row fashion (the last rectangle won't fit).

src/main-layout.m

Build and Run

This is a mulle-sde project.

It comes with its own virtual environment and list of dependencies. To fetch and build everything say:

mulle-sde craft

Then run the executables found in kitchen/Debug.
